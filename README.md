# Walr AI Skills

This is a collection of instruction files that help an AI assistant give correct, helpful answers
about working with Walr surveys.

Made and maintained by [MI Pro](https://www.mipro.no) - reach out there with questions or
corrections.

## What's inside

- **dcv1-dcv2-script-conversion** - help with converting or fixing a question's script when moving
  a survey between Walr's two page models.
- **walr-filters-and-answer-control** - help with Walr's built-in filters and answer logic, so you
  can solve things without writing a script.
- **walr-css-and-themes** - help with styling a survey (CSS and themes) without writing a script.

Each of these is a folder with a `SKILL.md` file inside it. That file is the actual instructions.
Some folders also have extra files with more detail, used together with the main file.

## How to download this

1. Click the green **Code** button near the top of this page.
2. Click **Download ZIP**.
3. Unzip the downloaded file on your computer.

## How to use it

1. Open the folder for the topic you need help with.
2. Open the `SKILL.md` file inside it (and any other files in that folder).
3. Copy the text and paste it into your conversation with your AI assistant, along with your
   question.

Some AI tools also let you upload files or add your own custom instructions/knowledge directly. If
yours does, you can add the whole folder there instead of copying and pasting each time.

## A note on accuracy

This is not an official Walr product, and it isn't made or approved by Walr. Some details are
marked inside the files as not fully confirmed. Check anything important against your own survey
before relying on it.
